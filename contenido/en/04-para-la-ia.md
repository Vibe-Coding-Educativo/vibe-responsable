# Instructions for creating with AI

## How to use them

The guide's recommendations can be given directly to the artificial intelligence (AI), so that the work of following them does not fall on the person. There is a file of instructions for this, which can be downloaded and used with any tool. It contains only what the guide asks for; what the material must do is described separately, as always.

The file is handed over at the start:

- **On a chatbot's website**, it is attached to the first message, together with the description of the material to be created and the instruction «follow the instructions in the attached file».
- **In a coding agent or a code editor with AI**, it is saved in the project folder as an instructions file, and the AI takes it into account in every session.
- **On app-building platforms**, it is pasted into the project's permanent instructions, which many offer in their settings or as a file in the project itself.

If the AI has not been told who the author is or where the resource will be published, the instructions require it to ask before starting. When finished, it is advisable to ask it, in the same conversation, for the [VCER evaluation](vcer.html#how-to-evaluate-a-resource), which points out what is missing. That review does not replace the person's own, since the model also makes mistakes when reviewing its own work.
